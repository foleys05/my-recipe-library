# My Recipe Library

A free, mobile-friendly searchable recipe website with 7 starter recipes and original photographed pages.

## Publish with GitHub Pages (no paid plan needed)
1. Create a free GitHub account at https://github.com/signup.
2. In GitHub, create a new **Public** repository named `my-recipe-library`. Do not initialize with a README.
3. Choose **uploading an existing file** and upload **index.html**, **recipes.json**, and the **images** folder contents (create an `images` folder in the repo and upload the seven JPG files there). Commit changes.
4. Open repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and Save.
5. After publishing, visit `https://YOUR-USERNAME.github.io/my-recipe-library/`. Publication may take a few minutes.
6. In Safari, tap Share → Add to Home Screen.

**Important:** GitHub Pages for free repositories is public. The recipes and photos will be publicly accessible. Do not upload private information. Favorites and notes save only in the browser where used, and can be lost when browser data is cleared.

## Update recipes
Edit `recipes.json` and add a matching photo in `images`, then commit the changes. Or share the latest site files with ChatGPT along with new recipe photos to generate an updated version.
